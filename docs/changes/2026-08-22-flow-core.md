# Núcleo persistido de Flow

Implementada a fundação de Flow, versões, nodes e edges com validação estrutural, snapshots imutáveis, publicação transacional, RLS, audit, contratos iniciais do engine e UI administrativa textual. O domínio puro contém configs discriminadas e códigos de erro; Application usa permissions e Location confiável; a migration incremental aplica FKs compostas, draft único, triggers leves e RPCs atômicos. Catalog é validado por referência na publicação.

Arquivos centrais: `packages/domain/src/flows.ts`, `packages/application/src/index.ts`, `packages/schemas/src/index.ts`, `packages/database/src/index.ts`, `apps/admin/app/ui/flow-panel.tsx`, `supabase/migrations/20260822000200_flows.sql`, `supabase/tests/flow_rls.test.sql`, `docs/domain/flows.md` e ADR-0004.

Foram adicionados testes de domínio/application e pgTAP para validação, autorização, isolamento, publicação e imutabilidade. Resultados constam no CI e no relatório. Canvas, runtime, sessões e commerce permanecem fora do escopo.
