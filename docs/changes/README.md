# Registros de implementação

Cada entrega de implementação deve possuir um registro datado contendo:

- o que foi feito;
- como foi implementado;
- decisões e trade-offs relevantes;
- arquivos principais;
- comandos e validações executados;
- limitações, riscos e débitos adiados.
